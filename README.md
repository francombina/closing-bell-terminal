# 📊 Closing Bell Terminal

Monitor de mercado en tiempo real diseñado para centralizar el seguimiento diario de precios y noticias en vivo en una única interfaz limpia y rápida.

🔗 **[Ver Terminal en Vivo](https://francombina.github.io/Closing-Bell-Terminal/)**

## 🎯 Problema que resuelve
En la operatoria diaria de mercado de capitales, la información suele estar fragmentada en múltiples pantallas y fuentes. Esta herramienta consolida las cotizaciones y métricas clave para agilizar la toma de decisiones intradiaria sin fricción visual.

## ⚙️ Arquitectura y Funcionalidades
* **Ingesta y actualización de datos:** Conexión y normalización de series de precios de mercado para visualización en vivo.
* **Foco en experiencia de análisis:** Interfaz optimizada (Dark Mode / diseño vectorial limpio) pensada por y para analistas financieros.
* **Despliegue ligero:** Arquitectura frontend de carga instantánea alojada en GitHub Pages.

## 🛠️ Stack Técnico
* HTML5 / CSS3 / JavaScript
* Integración de feeds de datos financieros y APIs
* GitHub Pages (CI/CD)
